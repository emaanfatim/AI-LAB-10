# 🛒 Retail Smart Billing System (Tkinter Project)

## 📌 Description

This project is a Smart Retail Billing System developed using Python and Tkinter. It simulates a real-world Point of Sale (POS) system with intelligent billing features such as AI-based discount rules and item suggestions.

---

## 🎯 Features

* User-friendly GUI using Tkinter
* Input validation (name, contact, numeric values)
* AI-based discount calculation
* Tax (5% GST) calculation
* Smart item suggestions
* Professional receipt generation
* Save receipt as `.txt` file
* Clear and Exit functionality

---

## 🧠 AI Logic

* Discount based on purchase amount:

  * ≥ 500 → 5%
  * ≥ 1000 → 10%
  * ≥ 2000 → 15%
  * ≥ 3000 → 20%
* Additional 5% discount for quantity ≥ 10
* System applies the maximum of manual or AI discount

---

## ⚙️ Technologies Used

* Python
* Tkinter
* datetime module

---

## ▶️ How to Run

1. Install Python
2. Open terminal in project folder
3. Run command:

   ```
   python cafe_billing_system.py
   ```

---

## 📊 Output

* Generates a formatted receipt
* Displays subtotal, discount, tax, and total
* Allows saving receipt as a text file
